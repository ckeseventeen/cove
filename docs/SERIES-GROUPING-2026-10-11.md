# 剧集归并与海报 · 2026-10-11

问题：部分电视剧每一集单独成为一部作品、各有一张海报（如《大明王朝1566》）；部分作品海报错误。

用真实资料库（百度网盘，2288 个视频）逐个文件跑归并逻辑，找出全部问题：

| 现象 | 例子 | 处理 |
| --- | --- | --- |
| 集号紧贴分辨率标记，未识别为剧集 | `大明王朝1566HD1080P01.mkv` | 识别 `HD1080P01`、`4K01` 等 |
| `SE03.01` 形式未识别，标题变成 “S” | `绝丨命毒师 第三季/SE03.01.mkv` | 识别 `SE03.01`，季号取 03 |
| 同一部剧按季分成多部作品 | 黑镜 / Black Mirror，权力的游戏 / Game of Thrones，神探夏 / 神探夏洛克 | 同一剧集文件夹下的各季文件夹合并为一部；季号不能重复，避免把“2024最高分英美剧”里各剧的第一季合在一起 |
| 标题残留季、画质、标签 | `庆余年（`、`Arcane Season1`、`我们与恶的距离第一季`、`神盾局特工第1-7季`、`【台剧】我们与恶的距离2` | 清理季名、括号画质、开头标签、与季号相同的结尾数字 |
| 合集序号导致匹配错误 | `10-死侍` 匹配到“X战警动画系列” | 去掉开头的 `10-` 序号 |
| 同名不同年份的电影共用一张海报 | Iron Man 2008 / 2010 / 2013 | 电影按“标题 年份”查询 TMDB |
| 花絮单独成为一部作品 | `装腔启示录/纪录+花絮` | 花絮文件夹作为该剧的“特别篇”，排在各季之后 |
| 分集纪录片每集一部 | `美国商业大亨传奇.Part1…Part4` | 名称不含年份时 `PartN` 视为分集（带年份的如《死亡圣器 Part 1 2010》仍是电影） |
| 片名后带发布信息 | `沉默的羔羊 双语字幕 HR-HDTV…` | 去掉字幕、编码、分辨率等说明 |

结果：作品数 416 → 362；对比修改前后，只有《大明王朝1566》46 集和《美国商业大亨传奇》4 集由“电影”变为“剧集”，没有任何电影被误判为剧集，其他剧集的集号没有变化。

## 海报缓存

- 海报缓存升级为 `movie-v5`：记录当次查询所用的名称。作品因归并规则变化而改名后，旧结果不再使用，会按新名称重新查询；“修正匹配”的手动名称继续优先。
- 数据库第 6 版删除旧的 `movie-v4` 缓存。升级后第一次打开“影视”时海报会随滚动重新获取。
