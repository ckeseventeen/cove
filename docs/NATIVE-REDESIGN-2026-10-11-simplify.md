# Cove 界面精简 · 2026-10-11

使用反馈：按钮与操作重复太多。原则：每个功能只保留一个主要入口；次要操作放进菜单栏、右键菜单或“⋯”菜单；没有内容时不显示控件。

| 位置 | 精简前 | 精简后 |
|---|---|---|
| 工具栏（未播放时） | 边栏开关、返回/前进、5 个灰色播放按钮、空白显示屏、音量、歌词、待播清单 | 只有返回/前进 |
| 工具栏（播放音乐时） | 随机、上一首、播放、下一首、重复 + 显示屏 + 音量、歌词、待播清单 | 上一首、播放、下一首 + 显示屏 + 音量、歌词、待播清单；随机与重复在待播清单和全屏播放器中 |
| 边栏 | 首页、文件、影视、音乐；位置；媒体文件夹（悬停刷新、管理按钮）；设置、帮助 | 首页、影视、音乐；位置；媒体文件夹。设置用 ⌘,，帮助在“帮助”菜单 |
| 首页 | 继续播放 + 资料库三格 + 位置列表 | 继续播放（新用户显示引导） |
| “文件”页、“媒体文件夹”页 | 与边栏重复的独立页面 | 删除；账号与媒体文件夹的管理并入“设置”，每行一个“⋯”菜单 |
| 添加存储入口 | 边栏 +、文件页标题按钮、文件页列表行、首页 | 边栏“位置”旁的 +、设置页、⌘N |
| 影视页 | 类别、过滤框、年份、排序 | 类别、排序（搜索用边栏搜索框） |
| 音乐页 | 播放、随机播放、过滤框、排序弹出菜单 | 播放、随机播放；点击列标题排序 |
| 作品详情 | 播放、修正匹配；单文件影片还列出一个重复的“播放”文件行 | 播放、“⋯”（修正匹配、在文件中显示）；只有多版本或剧集时才列出文件 |
| 文件浏览器 | 资料库、新建文件夹、粘贴、视图切换、过滤 | “添加到资料库”（仅可添加时出现）、“⋯”（新建文件夹、粘贴、显示方式、刷新）、过滤 |
| 歌词面板 | 关闭按钮、全文、重新匹配常驻 | 只在离开当前行时显示“回到当前”；全文与重新匹配在右键菜单 |
| 视频控制条 | 单个视频也显示灰色的上一个/下一个 | 只有多集时显示 |

快捷键调整：⌘1 首页、⌘2 影视、⌘3 音乐。
