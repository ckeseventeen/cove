# 多端同步（2026-10-23）

几台装了 Cove 的电脑（macOS / Windows 均可）通过一个它们都能读写的文件夹保持一致。代码在 `src-tauri/src/sync.rs`，设置在“设置 › 多端同步”。

## 同步什么

| 内容 | 合并规则 |
| --- | --- |
| 媒体文件夹（影视 / 音乐 / 文档 / 课程） | 对方有、本机没有就添加并在后台扫描；一方移除后，其他电脑也移除 |
| 播放进度（含课程学习进度、标为已看 / 未看） | 每个文件取更新时间较新的一条；标为“未看”会删除其他电脑上的进度 |
| 阅读进度（PDF 页码） | 每个文档取较新的一条 |
| 播放次数、最近播放时间 | 取较大值（最常播放 / 最近播放） |
| 播放列表 | 每个列表取较新的版本（名称和歌曲顺序）；删除会同步 |

不同步：本机磁盘上的文件夹（各电脑路径不同）、密码与授权令牌、百度 / TMDB 开放平台配置、界面偏好、影视资料缓存、离线视频。

## 怎么同步

- 同步位置是一个存储账号上的一个文件夹（默认 `/Cove 同步`）：百度网盘、WebDAV、SMB 共享，或本机上一个由其他应用同步的文件夹（OneDrive、iCloud 云盘、坚果云）。每台电脑各自选择，指向同一个地方即可。
- 每台电脑只写自己的文件 `cove-<设备 ID>.json`，读其他电脑的文件并合并，因此不会互相覆盖。文件内容没变时不重写。
- 启动 20 秒后同步一次，之后每 5 分钟一次；修改同步设置、点“立即同步”、或同步添加的文件夹扫描完成时立即再同步。
- 同一个文件在几台电脑上用“账号身份 + 网盘内路径”对应：账号身份记在 `accounts.sync_identity`——百度网盘是用户 uk，Google Drive 是 permissionId，OneDrive 是 drive id，WebDAV 是服务器地址，SMB 是共享地址。本机还没扫描到的文件，其记录留在对方的同步文件里，扫描后下一轮自然合并。
- 删除用墓碑记录（`sync_deleted`），由删除媒体文件夹、标为未看、删除播放列表的 store 方法在同一事务里写入。记录与墓碑比较时间，较新的生效，所以移除后再添加的文件夹会重新同步。
- 播放列表里有本机尚未扫描到的歌曲时，本机这份的更新时间记早一秒：下一轮会再从完整的那份补齐，且本机的不完整版本不会覆盖其他电脑。

## 已知限制

- 以各电脑的系统时钟比较新旧；时钟相差很多时，较新的判断可能不准。
- 同一秒内的修改和删除，删除优先。
- 移除整个存储账号不会同步到其他电脑（只移除本机的）。
