# Cove 原生化改造与验收 · 2026-10-10

目标：界面、交互、架构与系统集成向原生 macOS App（访达、音乐、TV、系统设置）看齐。本轮是代码改造与本机验收；云端账号、真实长片与公证分发不在本轮验收范围。

改造前的前端与被修改的 Rust 文件已备份到 `.audit-backup/frontend-before-native-redesign-20261010/`（Git 忽略）。原因：Git HEAD（9 月 12 日）早于当时的工作区，未提交的代码不在 Git 中。

## 审查发现

| 类别 | 问题 | 处理 |
|---|---|---|
| 界面 | 样式由 5 轮叠加组成（荧光绿、苹果蓝、浅蓝“Space”、中性灰、粉色音乐），大量死代码与 `!important` 互相覆盖；只有深色 | 重写为一套设计令牌：AppKit 语义色、macOS 字号、控件尺寸；跟随系统浅色/深色与高对比度 |
| 界面 | 网页式交互：手型光标、悬停上浮、可选中界面文字、网页右键菜单、自定义滚动条 | 默认箭头光标、无上浮动画、界面文字不可选、原生右键菜单、系统滚动条 |
| 系统集成 | 无应用菜单与快捷键；无媒体键/控制中心；边栏是 CSS 模糊 | 原生菜单栏与快捷键；`MPRemoteCommandCenter`/`MPNowPlayingInfoCenter`；`NSVisualEffectView` 边栏材质；红绿灯居中于 52pt 工具栏 |
| 架构 | `App.tsx` 660 行、约 25 个状态；条件 return 后调用 Hook；作品分组在 6 处重复计算；全局 Escape 一次关闭所有弹窗；`MutationObserver` 监听整棵 DOM | 拆分为窗口外壳 / 导航历史 / 资料库 Hook / 播放器 Context；作品只计算一次；弹窗栈式 Escape 与焦点陷阱 |
| 性能 | 播放进度每 0.5 秒更新会重渲染整页 | 播放状态放在外部 store，只有进度条与歌词订阅 |
| 逻辑 | 在文件浏览器直接播放音乐会打开黑色视频层（`media_kind` 只取来源目录） | 查询回退到文件自身的 `media_kind` |
| 逻辑 | 从文件浏览器播放歌曲时沿用旧的音乐队列，导致“下一首”不可用 | 后台开始的新歌曲使用同目录播放列表作为队列 |
| 逻辑 | 百度缓存直链再次追加 `access_token` | 只为新解析的直链追加令牌 |
| 逻辑 | 退出应用最多丢失 30 秒播放进度 | 退出时保存进度 |
| 逻辑 | 关闭窗口会停止音乐 | 音乐继续播放、窗口隐藏；视频仍停止并返回资料库 |
| 安全 | mpv 控制套接字与日志写在共享 `/tmp`；退出后残留套接字 | 移到用户私有 `$TMPDIR`，退出时清理 |
| 细节 | 符号链接文件夹显示为文件；文件大小混用 1024 与 1000 进制；用户可见文字残留 “Nimbus” | 跟随符号链接；统一十进制（同访达）；统一为 Cove |

## 交互变化

- 工具栏：返回/前进、边栏开关；中部为“音乐”式播放器（封面、标题、进度）；右侧音量、歌词、待播清单。
- 右侧检查器：歌词（同步滚动、点击跳转、全文）与待播清单（提前/延后/移除、随机/重复）。点封面进入全窗口“正在播放”。
- 列表：单击选中、双击或回车播放/打开；右键菜单包含“下一首播放”“添加到待播清单”“在文件中显示”等。
- 文件：路径栏、列表/图标视图、修改日期/大小/种类排序、过滤、空格快速查看、拷贝粘贴与拖放、底部状态栏、“资料库”菜单设置媒体文件夹。
- 导航历史：⌘[ / ⌘] 与工具栏按钮，返回时恢复滚动位置；搜索清空后回到搜索前页面。
- 首页：新用户引导、继续播放（剩余时间）、资料库入口、位置。设置页改为“系统设置”式分组列表；帮助页列出快捷键。
