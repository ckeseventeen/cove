# 新功能一批 · 2026-10-22

| 功能 | 用法 | 说明与验证 |
| --- | --- | --- |
| 外挂字幕 | 自动 | 打开视频时列出同目录及 `Subs`/`字幕` 子文件夹，按发布名、同一集（S01E03、E03、第3集）或单视频文件夹匹配；简体 > 中英 > 繁体 > 英语，已开启的中文或 AI 字幕不被替换。mpv 自带的本地搜索关闭，内嵌字幕优先中文。原生测试：第 1 集加载 3 条且选中中英双语，第 2 集只加载自己的。 |
| 自动更新媒体文件夹 | 自动 | 启动 30 秒后检查；网盘 6 小时、本地与 SMB 30 分钟；本地文件夹另用 FSEvents，文件变化 5 秒后重扫；失败的文件夹 1 小时后再试；有新增时提示“新增 N 个”。真实资料库：4 个文件夹 3 秒内完成，影视新增 1 个。 |
| 剧集进度 | 自动；右键标记 | 卡片显示“看到第 N 集 / 下一集 / 已看完 / 还剩 N 分钟 / 已看过”，海报进度条或勾；详情页“继续播放第 N 集”，已看集打勾；可标记已看/未看及“之前各集”。 |
| 音乐艺人 / 专辑 | 音乐 › 歌曲·艺人·专辑 | 艺人来自文件名（拆分合唱、合并大小写）；专辑来自在线资料，“获取专辑信息”两首并行补全，可停止；专辑页可用 ⌘[ 返回。 |
| SMB 共享 | 添加存储 › SMB 共享 | macOS NetFS 装载到应用自己的目录（访达已装载则复用），资料库中保存共享内的相对路径；浏览、扫描、播放、PDF、字幕都按本地处理；暂为只读。连接失败 2 秒内中文提示、无系统弹窗；尚未连接真实共享验证。 |
| 海报补全 | 自动 | TMDB 找不到时依次尝试：去掉“国粤台英四语/官中/中英双字”等、英文部分、中文部分、去掉续集编号，均保留年份；对资料库中 16 部缺海报的作品补全 10 部，其余为拼音缩写名或 TMDB 无条目，需“修正匹配”。 |
| 智能播放列表 | 边栏 › 播放列表 | 最近添加（30 天内）、最常播放、最近播放；有内容才显示。数据库第 8 版：`media_files.added_at`、`play_history`。 |
| 小窗播放 | 控制条按钮、右键、P | 视频窗口缩到屏幕右下角并浮在其他 App 之上（所有桌面），保持画面比例；再按、Esc、双击或 F 恢复原位置；停止播放必定恢复。原生测试：缩小、恢复、再缩小、停止，窗口位置与层级均正确恢复。 |
| 离线下载 | 详情 ⋯ / 剧集右键 / 电影卡片右键 | 经流代理逐个下载到应用数据目录 `Offline`，断线从 `.part` 续传；下载会话不受停止播放影响；已下载的视频播放时不走网络；设置 › 离线视频管理；本机与 SMB 视频不提供下载。测试：本地 HTTP 服务器上完整下载与断点续传。 |
| Google Drive / OneDrive 登录 | 添加存储 | OAuth 2.0 + PKCE，回环地址回调，令牌自动续期；需在 `.env` 配置自己注册的应用 ID（见 README），未配置时仍可粘贴令牌。未用真实应用验证。 |
