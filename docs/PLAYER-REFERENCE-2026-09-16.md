# 播放器对标与验收

## 参考依据

- Apple Music 官方 MiniPlayer / 全屏播放器说明及配图：https://support.apple.com/en-au/guide/music/mus71d7dcfce/mac
- Apple Music 随机与循环：https://support.apple.com/en-us/HT212266
- Spotify 官方队列流程：https://support.spotify.com/us/article/play-queue/
- IINA 官网及官方播放器截图：https://iina.io/ 、https://iina.io/images/sc-sky.png
- VLC 官方热键资料：https://thresh.videolan.me/vlc-user/userguide/hotkeys.html

复用成熟的交互分工，不复制品牌素材或引入其他播放器源码。音乐采用封面、歌词与待播列表，随机与循环分别控制；视频采用简洁浮动控制条，音轨、字幕、速度集中在设置面板。Cove 保留本机和云端文件入口。

## 本轮实现

| 场景 | 调整 |
|---|---|
| 音乐列表播放 | 启动时保存队列快照，浏览、搜索和排序不再改变正在播放的队列 |
| 随机播放 | 随机排序尚未播放的部分，保留当前曲目与播放历史；同一轮不重复抽取 |
| 循环 | 关闭、全部、单曲三态，与随机开关独立；手动下一首不受单曲循环阻止 |
| 上一首 | 已播放超过 3 秒先回到曲首，否则返回队列上一首 |
| 队列 | 显示正在播放／接下来播放，可提前、延后或移除待播项；浮层避免被底栏模糊效果裁切 |
| 音量 | 静音后恢复先前音量，不突然恢复到 100% |
| 进度条 | 视频和音乐共用滑块；鼠标一次提交、指针取消回退、键盘即时提交 |
| 歌词 | 方形封面、长句换行、同步高亮、全文模式、手动浏览后恢复跟随；匹配失败保留已有元数据 |
| 视频控件 | 音量、播放／暂停、前后跳转、设置与选集分组；设置保留准确的 0.75×、1.25× 等标签 |
| 视频操作 | 单击暂停、双击全屏；Esc 依次关闭面板或退出全屏，不停止影片；返回按钮明确停止播放 |
| 控制条隐藏 | 暂停、播完或操作控件／面板时保持可见 |
| 自动续播 | 文件结束事件去重；切换视频从开头播放；音乐拒绝旧文件的结束状态触发跳曲 |
| 原生焦点 | 播放视频时将焦点交给控制窗口，并启用鼠标移动事件；保留原生标题栏点击区域 |

## 测试记录

- 前端构建通过；24 项逻辑测试通过，其中 5 项覆盖队列边界、单曲循环与手动下一首、随机去重及历史保留。
- 900×640 浏览器实际组件验收：封面正方形、长歌词换行、队列可见、提前待播曲目、移出队列、Esc 仅关闭队列。
- 原生控制窗口修复后的验收另见下方最终结果。

## 尚未实现的高级能力

画中画、系统媒体键／控制中心、缩略图预览、章节导航、字幕延迟与本地字幕导入、独立迷你窗口、队列跨重启恢复及拖拽排序仍未实现。本轮不把这些描述为已完成；它们需要播放器内核或原生窗口层的独立设计与验证。当前队列调序使用可访问的提前／延后按钮。

## 原生验收结果

2026-09-16 在已安装的 Cove 中用已有视频实测：设置面板可见，音轨与字幕选择器显示当前选择；暂停后按钮切换为播放，空格恢复播放；Esc 先关闭设置，F 进入全屏，Esc 退出全屏后保持同一影片和进度。实际发现主窗口抢焦点，已将焦点交给控制子窗口；加载阶段先显示退出入口，并在播放文件信息首次读取失败后重试。

个人配置构建仅安装于本机，安装产物与备份均由 Git 忽略规则排除。没有上传新的安装包。
